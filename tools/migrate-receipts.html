Receipt migration — base64 in records → Storage bucket

One-off admin tool. Open it locally or from the deployed site, sign in with an admin account, and run it once.
Read before running.
  • Run supabase-storage-setup.sql first — the pcf-receipts bucket must exist.
  • Deploy the app changes first, so new uploads already go to the bucket.
  • This is additive and reversible. It uploads each file and adds a path to the record. The inline bytes are left in place. Nothing is deleted here — if anything looks wrong, ignore the paths and the portal keeps rendering from the inline copies.
  • Only after you have verified receipts still open should you run supabase-strip-inline-receipts.sql to reclaim the space.
  • Run it during a quiet window. It rewrites record rows, so an edit saved at the same instant could be overwritten.
